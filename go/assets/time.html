Adapter chấm công

Endpoint nhập liệu chuẩn POST /v2/time/punches/import chỉ cho HR/Admin, yêu cầu session + CSRF. HTTP pull connector hỗ trợ API JSON qua HTTPS; chưa nhận diện hãng/model máy chấm công thực tế.

{"source":"DEVICE-API","device_id":"SIM-GATE-01","events":[{"event_id":"unique-001","badge_id":"EMP-0012","direction":"IN","occurred_at":"2026-11-04T08:00:00+07:00"}]}

Yêu cầu đầu vào: event ID ổn định, badge mapping theo ngày hiệu lực, timezone rõ ràng, truy cập thiết bị qua gateway phân đoạn IT/OT.
