OrgAxis API

Local-only · Synthetic data

Go binary / SQLite · Theo ngày hiệu lực. Các API dưới đây yêu cầu header X-API-Key: demo-local-key. Bản demo không có RBAC hoặc tenant-scoped authentication.

Gọi API

curl.exe -H "X-API-Key: demo-local-key" "http://127.0.0.1:6666/v1/people/EMP-0030/manager?as_of=2026-11-18"

Chỉ chạy trên loopback 127.0.0.1. Dữ liệu mẫu được sao chép vào data/orgaxis.sqlite3 khi chạy lần đầu.
